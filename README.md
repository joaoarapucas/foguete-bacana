# foguete bacana
projeto de extensão dos alunos do Senac com o objetivo de lançar um foguete guiado por um microcontrolador!!! 

## sobre o projeto

<p>A ideia é fazermos um foguete d'água usando o microcontrolador Raspberry Pi Pico W.  O foguete terá dois estágios, com um paraquedas após ele atingir o apogeu. </p>
<p>A transição entre estágios será feita usando um servo motor e o microcontrolador !!! </p>
